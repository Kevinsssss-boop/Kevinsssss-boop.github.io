关于About

我是江学文，广东财经大学在读，正在找数据分析方向的岗位。 I'm Kevin Jiang, studying at Guangdong University of Finance & Economics and looking for a data analytics role.

我做的事大体是这样一条线：在实习里遇到一件反复手工做的事，先想它能不能被自动化； 能用脚本解决的就不写系统，需要多人协作和留痕的才做成工具。 上面那两个内部工具都是这么来的——它们都跑在真实业务里，处理的是真实的数据， 所以源码不公开，这里只讲设计和取舍。 My work tends to follow one line: hit something repetitive during an internship, then ask whether it can be automated. If a script is enough, write a script; only build a tool when multiple people need to collaborate and leave an audit trail. Both internal tools above came from that — they run against real business data, so the source stays private and what's here is the design and the trade-offs.
